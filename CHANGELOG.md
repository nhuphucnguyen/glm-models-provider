# Changelog

## 1.1.0

- **Added GLM-5.4**, Z.AI's new flagship model and the first built on the Loop
  Transformer architecture. It supports image input, a 1M-token context and
  128K output, and is available on all Coding Plan tiers.
- GLM-5.4 uses fewer Coding Plan credits per token than GLM-5.3, and weekly
  quota plans get 1.5× the GLM-5.3 quota for it.
- GLM-5.3 and GLM-5.3-Flash remain available.

## 1.0.0

- First release under the `phucnguyennhu.glm-models-provider` id: GLM-5.3 and
  GLM-5.3-Flash with configurable thinking effort, temperature presets, and
  usage and quota display.
